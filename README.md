# Responsible AI Monitoring Module

## Project Overview
The Responsible AI Monitoring Module is a governance-oriented AI monitoring platform designed to evaluate machine learning systems for fairness, transparency, explainability, drift, and ethical risks.

The project focuses on Responsible AI principles by continuously monitoring deployed AI models through interactive dashboards and governance indicators.

## Features
- Accuracy Monitoring
- Bias Detection
- Drift Detection
- Explainable AI (XAI)
- Governance Risk Scoring
- Interactive Streamlit Dashboard

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Fairlearn
- SHAP
- Evidently AI
- Plotly
- Pandas
